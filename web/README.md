# Agora (Web)

Static Next.js website for the public curated mod directory.

## Setup

```bash
npm install
```

## Build

The website reads `registry-web.json` (generated by the compiler) at build time.

1. Generate the web artifact:
   ```bash
   python compiler/compile.py --skip-sign
   ```
   This produces both `registry.db` and `registry-web.json`.

2. Build the static site:
   ```bash
   npm run build
   ```

This produces a static export in `dist/` that can be deployed to Vercel or GitHub Pages.

## Development

```bash
npm run dev
```

Set `REGISTRY_WEB_JSON_PATH` to override the default `../registry-web.json` lookup path.
